# AI-Based Intrusion Detection System

This project is an anomaly detection system built using K-Means clustering.

## Features
- Detects abnormal network traffic patterns
- Uses clustering to identify anomalies
- Applies distance-based thresholding

## Technologies
- Python
- Scikit-learn
